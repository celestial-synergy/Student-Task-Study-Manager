# Student Task & Study Manager

## Problem Statement

Students have to keep track of different assignments, study tasks, subjects and deadlines. When there are many tasks at the same time, it can be easy to forget what needs to be completed.

This project is made to provide a simple way for students to store their tasks and keep track of their progress in one place.

## Scope

The project is a Java-based console application for managing academic tasks. It allows a student to enter their details, add subjects, create tasks, set deadlines and priorities, and keep track of completed and pending tasks.

The project mainly focuses on applying Java programming concepts such as classes and objects, ArrayList, methods, exception handling and file handling.

## Target Users

The main users of this application are students who want a simple way to organize their academic work.

## Main Features

* Add and view student details
* Add and view subjects
* Add academic tasks
* Set task deadlines and priorities
* View all tasks
* View pending and completed tasks
* Mark tasks as completed
* Delete tasks
* View a progress report
* Save task information to a file

## Technologies Used

* Java
* Object-Oriented Programming
* ArrayList
* Exception Handling
* File Handling
* GitHub
